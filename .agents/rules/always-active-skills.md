# Always-Active Mandatory Skills & Engineering Disciplines

The following skills and disciplines are mandatory and active on every prompt turn across this project:

## Core Project Skills & Disciplines
* **`Next.js 16 App Router Architecture`**: Server & Client component boundaries (`"use client"`), dynamic routing (`[id]`), Next.js middleware, and Suspense wrappers.
* **`Supabase & PostgreSQL Engineering`**: Direct database schema queries, Remote Procedure Calls (RPCs), Row Level Security (RLS), and Postgres Realtime channel subscriptions (`supabase-postgres-best-practices`).
* **`Role-Based Access Control (RBAC)`**: Dual-layer route guarding, role normalization (`ATTENDEE`, `COORDINATOR`, `ADMIN`), safe redirection resolution, and session cookie synchronization (`rbac-permissions`).
* **`Automated Testing (Vitest)`**: Writing unit and integration test suites covering edge cases, regex validators, data transformers, and API contracts.
* **`Tailwind CSS v4 & UI Design`**: Responsive layouts, dark glassmorphic styling, gradient text, modal backdrops, and interactive hover states.
* **`TypeScript Type Safety`**: Strict compile-time typing, database schema typings (`database.types.ts`), and interface definitions.
* **`DevOps & Git Operations`**: Automated verification builds (`npm run build`), status verification, and continuous deployment to Vercel via GitHub `main` (`deploy-to-vercel`, `permissioned-github`).
* **`graphify`**: Codebase knowledge graph navigation, symbol tracing, and structural dependency mapping.

## Standard Engineering Protocols
* **`spec-driven-development`**: Spec-first planning, user approval, and verification cycle.
* **`ponytail`**: Surgical, minimal code changes with zero bloat (YAGNI).
* **`vercel-react-best-practices`**: React 19 and Next.js performance optimizations.
* *(Hook)* **`auto-commit-on-complete`**: Automatic git commit staging upon task completion.

These protocols govern the core engineering standards of this workspace. Do not deviate from them.
